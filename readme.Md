# 🏆 ContestHub Server - Backend API

RESTful API server for ContestHub - a creative contest management platform.

## 🌐 Live Server

**[ContestHub API](https://contesthub-server-lovat.vercel.app)**

## ✨ Key Features

1. **RESTful API Architecture** - Clean, organized endpoints following REST conventions

2. **JWT Authentication** - Secure token-based authentication with Firebase Admin SDK

3. **Role-Based Access Control** - Middleware for Admin, Creator, and User permissions

4. **Stripe Payment Integration** - Secure payment processing for contest registration

5. **MongoDB Aggregation** - Complex queries for leaderboard rankings and statistics

6. **Contest Management APIs** - Full CRUD operations for contests with approval workflow

7. **Participant Tracking** - Registration, submission, and winner declaration endpoints

8. **User Management** - Role updates, profile management, and admin controls

9. **Payment History** - Transaction records and verification endpoints

10. **Statistics Dashboard** - Aggregated data for platform analytics

## 🛠️ Technologies Used

- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB
- **Authentication:** Firebase Admin SDK
- **Payments:** Stripe API
